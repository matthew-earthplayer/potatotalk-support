PotatoTalk 隱私權政策

最後更新：2026 年 8 月 27 日

本隱私權政策說明 PotatoTalk V1 如何處理與 App 使用相關的資料。PotatoTalk 由 FANG-TING LI 提供。

1. 不需要建立帳號

PotatoTalk V1 不需要註冊、登入或建立使用者帳號。

2. 麥克風與口說錄音

當你使用口說練習功能時，PotatoTalk 會在需要時要求麥克風權限，並在你的裝置上錄製口說練習。

  • 錄音用於 App 內的口說／跟讀練習流程。
  • 依目前 V1 production 版本，錄音不會上傳到 PotatoTalk 伺服器。
  • 錄音不會用於廣告、追蹤或建立使用者檔案。
  • 練習錄音屬於本機暫存資料，依練習 session 的生命週期進行清理。

3. 儲存在裝置上的資料

PotatoTalk 會在你的裝置上儲存提供 App 功能所需的資料，例如：

  • App 設定，例如語言、音量及震動設定；
  • 學習與任務進度；
  • My Library／Review 資料；
  • App 內虛擬進度與獎勵資料，例如 coins、diamonds、成就或任務狀態。

依目前 V1 production 版本，這些資料儲存在裝置本機，沒有 PotatoTalk 雲端帳號或雲端同步。

4. Analytics、廣告與追蹤

依目前 V1 production 版本，PotatoTalk 沒有整合 analytics、廣告、跨 App 追蹤或 crash reporting SDK，亦沒有使用 IDFA 進行追蹤。

5. Production 網路傳輸

依目前 V1 production 資料流 audit，沒有發現 App runtime 將使用者資料或錄音傳送至 PotatoTalk 後端或外部語音辨識服務。開發環境中的測試工具不屬於 App Store production 版本。

6. 刪除資料

由於 PotatoTalk V1 沒有使用者帳號，也沒有 PotatoTalk 雲端個人資料庫，因此沒有線上帳號刪除流程。你可以使用 App 內可用的重置／清除功能移除部分資料；若要移除 PotatoTalk 儲存在裝置上的 App 資料，可刪除 App。

7. 第三方平台

PotatoTalk 使用 Apple iOS 及 React Native／Expo 生態中的系統與軟體元件來提供 App 功能。本支援網站若透過 GitHub Pages 發佈，網站存取也可能受 GitHub 自身的服務條款與隱私做法約束。

8. 政策更新

如果未來版本加入雲端同步、analytics、帳號、付款、外部語音服務或其他會改變資料處理方式的功能，本政策會相應更新。

PotatoTalk Privacy Policy

Last updated: August 27, 2026

This Privacy Policy explains how PotatoTalk V1 handles information related to use of the app. PotatoTalk is provided by FANG-TING LI.

1. No account required

PotatoTalk V1 does not require registration, sign-in, or creation of a user account.

2. Microphone and speaking recordings

When you use speaking practice, PotatoTalk requests microphone permission when needed and records your speaking practice on your device.

  • Recordings are used for the in-app speaking and shadowing practice flow.
  • In the current V1 production version, recordings are not uploaded to a PotatoTalk server.
  • Recordings are not used for advertising, tracking, or user profiling.
  • Practice recordings are temporary local data and are cleaned up according to the practice session lifecycle.

3. Data stored on your device

PotatoTalk stores data on your device that is needed to provide app features, such as:

  • app settings, including language, volume, and vibration preferences;
  • learning and mission progress;
  • My Library / Review data; and
  • in-app virtual progress and rewards, such as coins, diamonds, achievements, or quest state.

In the current V1 production version, this data is stored locally on the device. PotatoTalk does not provide a cloud account or cloud sync for this data.

4. Analytics, advertising, and tracking

In the current V1 production version, PotatoTalk does not integrate analytics, advertising, cross-app tracking, or crash-reporting SDKs, and does not use IDFA for tracking.

5. Production network transmission

Based on the current V1 production data-flow audit, no app-runtime path was found that sends user data or speaking recordings to a PotatoTalk backend or external speech-recognition service. Development-only testing tools are not part of the App Store production version.

6. Deleting data

Because PotatoTalk V1 has no user account and no PotatoTalk cloud database containing personal user data, there is no online account-deletion process. You can use available in-app reset or clear features for certain data. To remove PotatoTalk app data stored on your device, you can delete the app.

7. Third-party platforms

PotatoTalk uses system and software components from Apple iOS and the React Native / Expo ecosystem to provide app functionality. If this support site is published through GitHub Pages, access to the website may also be subject to GitHub's own terms and privacy practices.

8. Changes to this policy

If a future version adds cloud sync, analytics, accounts, payments, external speech services, or other features that change data handling, this policy will be updated accordingly.
